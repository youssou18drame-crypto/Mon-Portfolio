1ère année BTS SIO

Application Web MDS Avis

MyDigitalSchool — Projet scolaire

MDS Avis est une application web réalisée dans le cadre de ma formation en BTS SIO option SLAM.

Ce projet m'a permis de travailler sur différentes parties d'une application web : le front-end, le back-end, une API REST, la gestion des utilisateurs et la gestion des données.

🎯 Objectifs du projet

  • Concevoir une application web permettant de consulter et gérer des avis.
  • Développer une interface utilisateur avec Next.js et React.
  • Développer une API REST avec Node.js et Express.
  • Faire communiquer le front-end avec le back-end.
  • Gérer les utilisateurs et l'authentification.
  • Stocker et gérer les données de l'application.

⚙️ Fonctionnalités

  • Création d'un compte utilisateur.
  • Connexion à un compte.
  • Authentification des utilisateurs.
  • Consultation des avis.
  • Ajout d'avis.
  • Suppression d'avis.
  • Fonction « mot de passe oublié ».
  • Réinitialisation du mot de passe.
  • Communication entre le front-end et l'API REST.

💻 Technologies utilisées

Next.js React JavaScript Node.js Express Prisma API REST JWT Argon2 Git GitHub

🔐 Authentification et sécurité

  • Gestion de l'inscription des utilisateurs.
  • Gestion de la connexion.
  • Utilisation de JSON Web Token (JWT) pour l'authentification.
  • Utilisation d'Argon2 pour la gestion sécurisée des mots de passe.
  • Mise en place d'une fonctionnalité de récupération du mot de passe.

🎓 Compétences BTS SIO

  • Concevoir et développer une solution applicative.
  • Développer une interface web.
  • Développer et utiliser une API REST.
  • Gérer les données d'une application.
  • Assurer la maintenance corrective et évolutive d'une application.
  • Utiliser Git et GitHub pour la gestion des versions.
  • Mettre en œuvre des mécanismes d'authentification.
  • Participer à la sécurisation d'une application web.
