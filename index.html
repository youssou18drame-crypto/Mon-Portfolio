Veille technologique

L'intelligence artificielle dans le développement d'applications web

Dans le cadre de mon BTS SIO option SLAM, j'ai choisi de suivre l'évolution de l'intelligence artificielle dans le développement web. L'IA peut aujourd'hui aider à générer du code, comprendre un programme, rechercher des erreurs, créer des tests ou automatiser certaines tâches.

Problématique : Comment l'intelligence artificielle transforme-t-elle le développement des applications web, et quels sont ses avantages et ses limites pour les développeurs ?

🔎 Ma méthode de veille

J'utilise principalement daily.dev pour suivre les actualités liées à l'intelligence artificielle, au développement web et aux outils pour développeurs. Lorsque je trouve une information intéressante, je consulte aussi la source originale afin de la vérifier.

Sources suivies : daily.dev, GitHub / GitHub Blog, Stack Overflow, documentations officielles et ANSSI pour les sujets liés à la cybersécurité.

📰 Actualités suivies

5 mars 2026 · GitHub

GPT-5.4 arrive dans GitHub Copilot

GitHub a intégré GPT-5.4 à Copilot pour améliorer notamment le raisonnement et la réalisation de tâches de programmation complexes comportant plusieurs étapes.

Ce que j'en retiens : les assistants IA ne servent plus seulement à compléter quelques lignes de code. Ils peuvent aider sur des tâches de développement de plus en plus complexes.

Voir la source ↗
2 juin 2026 · GitHub

Des environnements isolés pour les agents IA

GitHub a présenté des environnements isolés, appelés sandboxes, permettant à Copilot d'exécuter certaines commandes et de travailler sur des fichiers dans un environnement contrôlé.

Ce que j'en retiens : plus une IA peut agir de manière autonome, plus il devient important de contrôler ses permissions et de sécuriser son environnement.

Voir la source ↗
13 juin 2026 · daily.dev

Comparaison des assistants IA de programmation

daily.dev compare plusieurs assistants comme GitHub Copilot, Cursor, Claude Code et Windsurf. Ces outils peuvent proposer du code, expliquer un programme ou aider à rechercher des erreurs.

Ce que j'en retiens : il existe de nombreux assistants IA et ils n'ont pas tous les mêmes fonctionnalités. Le développeur doit choisir l'outil adapté à ses besoins.

Voir la source ↗
8 août 2026 · daily.dev

Les assistants deviennent des agents de développement

Les outils d'IA évoluent vers des agents capables d'analyser un projet, d'intervenir sur plusieurs fichiers et de réaliser plusieurs étapes pour accomplir une tâche.

Ce que j'en retiens : l'IA devient plus autonome, mais le développeur doit toujours comprendre les modifications, tester le résultat et vérifier le code produit.

Voir la source ↗

✅ Avantages

Gain de temps, aide à la compréhension du code, recherche d'erreurs, génération d'exemples, tests, documentation et apprentissage de nouvelles technologies.

⚠️ Limites et risques

Le code généré peut contenir des erreurs ou des failles. Il faut également protéger les données confidentielles et toujours vérifier et tester les résultats.

💡 Conclusion personnelle

Cette veille m'a permis de comprendre que l'intelligence artificielle transforme progressivement le métier de développeur. Je pense qu'elle ne remplace pas le développeur, mais qu'elle devient un outil pour l'aider à travailler plus efficacement. Il reste indispensable de connaître les bases de la programmation pour comprendre, vérifier, tester et sécuriser le code proposé. Dans mon futur métier, je souhaite donc savoir utiliser l'IA tout en gardant un regard critique sur les résultats qu'elle produit.
